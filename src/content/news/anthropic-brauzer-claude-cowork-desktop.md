## Anthropic встраивает браузер в Claude Cowork для десктопа

**Кратко:** Anthropic интегрировал собственный браузер в десктоп-приложение Claude Cowork. Браузер открывается в боковой панели и позволяет загружать веб-страницы, читать их содержимое и выполнять клики.

**Что произошло**

Anthropic встраивает собственный браузер в Claude Cowork. Браузер открывается в боковой панели десктоп-приложения. Функция предназначена для загрузки страниц, чтения их содержимого и выполнения кликов.

**Что изменилось по сравнению с предыдущей версией**

Ранее Claude Cowork не имел встроенного браузера. Теперь пользователи могут взаимодействовать с веб-страницами напрямую из боковой панели приложения, без необходимости переключаться между окнами.

**Цены и доступность**

Информация о дате официального анонса, стоимости и доступности функции для всех пользователей Claude Cowork отсутствует.

**Почему это важно**

Встроенный браузер в AI-ассистенте расширяет возможности автоматизации задач, связанных с веб-серфингом. Это шаг к более автономным агентам, способным выполнять действия в интернете по команде пользователя.
