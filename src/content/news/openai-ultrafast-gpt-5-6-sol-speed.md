# OpenAI представила режим Ultrafast для GPT-5.6 Sol с рекордной скоростью генерации

**Кратко:** OpenAI запустила новый режим инференса Ultrafast для модели GPT-5.6 Sol. Заявленная скорость генерации достигает 750 выходных токенов в секунду.

**Что произошло**

OpenAI представила режим Ultrafast для своей модели GPT-5.6 Sol. Этот режим обеспечивает скорость до 750 выходных токенов в секунду.

**Что изменилось по сравнению с предыдущей версией**

Сравнение с предыдущими версиями модели или режимами инференса не приводится. Нет данных о том, насколько Ultrafast быстрее стандартного или быстрого режимов.

**Цены и доступность**

Информация о стоимости использования режима Ultrafast, дате выхода и регионах доступности не раскрывается.

**Почему это важно**

Скорость генерации в 750 токенов в секунду является одной из самых высоких среди современных языковых моделей. Это может существенно сократить время ожидания ответа для пользователей и открыть новые возможности для приложений, требующих низкой задержки, например, в чат-ботах реального времени или голосовых ассистентах.
