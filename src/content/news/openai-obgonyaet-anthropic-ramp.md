# OpenAI обгоняет Anthropic по темпам роста среди бизнес-пользователей Ramp

**Кратко:** В третьем квартале 2023 года OpenAI растет быстрее Anthropic среди бизнес-пользователей платформы корпоративных расходов Ramp. Данные предоставлены экономистом компании.

**Что произошло**
Экономист Ramp Ара Харазян отметил, что в текущем квартале (Q3) OpenAI показывает более высокие темпы прироста числа бизнес-клиентов по сравнению с Anthropic. Ramp — сервис для управления корпоративными расходами, используемый тысячами компаний. Наблюдение охватывает период с начала квартала по настоящее время.

**Что изменилось по сравнению с предыдущей версией**
Данные о динамике за предыдущие кварталы в отчете не приводятся. Информация является срезом текущей ситуации.

**Цены и доступность**
Стоимость корпоративных тарифов OpenAI и Anthropic не раскрывается. Обе компании предлагают API и бизнес-подписки.

**Почему это важно**
Бизнес-сегмент — один из главных драйверов монетизации генеративного ИИ. Более быстрый рост OpenAI среди пользователей Ramp указывает на предпочтения корпоративных заказчиков и может отражать эффективность продуктовой стратегии OpenAI. Данные также подчеркивают усиление конкуренции с Anthropic.

**Для пользователей AI-Sphere**
При выборе AI-ассистента для бизнеса стоит учитывать, что OpenAI быстрее набирает корпоративных клиентов на платформе Ramp. Рекомендуем отслеживать обновления карточек моделей на ai-sphere.ru.

**Сравнение с аналогами**
OpenAI (ChatGPT) и Anthropic (Claude) — лидеры рынка генеративных моделей. Оба предлагают API для бизнеса, но различаются по стоимости, безопасности и позиционированию. Данные Ramp показывают, что в Q3 OpenAI растет быстрее среди этой аудитории. Однако это не говорит о превосходстве по качеству — возможно, Anthropic фокусируется на других каналах привлечения.
