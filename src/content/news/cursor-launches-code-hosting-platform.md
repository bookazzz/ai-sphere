**Кратко:** Cursor, известный AI-редактор кода, запускает новую платформу для хостинга кода. Сервис позиционируется как прямой конкурент GitHub.

**Что произошло**

Cursor объявил о запуске собственной платформы для хостинга кода. Новая платформа будет конкурировать с GitHub — крупнейшим сервисом для хранения и управления кодом. Детали о функциональности и сроках запуска пока не раскрываются.

**Что изменилось по сравнению с предыдущей версией**

Ранее Cursor был известен исключительно как AI-редактор кода на базе VS Code. Запуск платформы для хостинга кода означает расширение экосистемы компании за пределы редактора. Это первый шаг Cursor в сегмент хранения и совместной работы с кодом, где доминирует GitHub.

**Цены и доступность**

Информация о стоимости, дате запуска и регионах доступности пока не опубликована.

**Почему это важно**

Запуск платформы для хостинга кода от Cursor — это попытка создать замкнутую экосистему для разработчиков, объединяющую AI-редактор и облачное хранилище кода. Если Cursor интегрирует AI-функции в хостинг (например, автоматический ревью кода или генерацию документации), это может составить серьезную конкуренцию GitHub, который пока ограничивается базовыми AI-инструментами.
