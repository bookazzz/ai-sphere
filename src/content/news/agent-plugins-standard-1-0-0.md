**Кратко:** Опубликована версия 1.0.0 стандарта Agent Plugins. Это первый стабильный релиз, который определяет единый формат для подключения внешних плагинов к AI-агентам.

**Что произошло**

Вышла версия 1.0.0 стандарта Agent Plugins. Стандарт описывает, как AI-агенты могут взаимодействовать с внешними инструментами и сервисами через плагины. Ранее подобные механизмы существовали в виде проприетарных решений отдельных платформ.

**Что изменилось по сравнению с предыдущей версией**

Это первый стабильный релиз. До этого стандарт находился в разработке или существовал в виде черновиков. Версия 1.0.0 фиксирует основные спецификации и становится отправной точкой для внедрения.

**Цены и доступность**

Стандарт опубликован в открытом доступе. Дата выхода — текущая. Распространяется бесплатно. Поддержка стандарта ожидается от ведущих платформ AI-агентов.

**Почему это важно**

Единый стандарт для плагинов упрощает разработку и интеграцию. Разработчики могут создавать плагины, совместимые с разными агентами, без необходимости адаптироваться под каждый API. Это ускоряет экосистему AI-агентов и снижает порог входа для создания новых инструментов.

**Для пользователей AI-Sphere**

С выходом стабильного стандарта стоит ожидать появления большего числа совместимых плагинов от разных разработчиков. Пользователи AI-Sphere смогут подключать их к своим агентам, расширяя функциональность. Следите за обновлениями в карточках моделей и инструментов.
