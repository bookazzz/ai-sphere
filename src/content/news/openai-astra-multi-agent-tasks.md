# OpenAI представила семейство моделей Astra для долгосрочных мультиагентных задач

**Кратко:** OpenAI разрабатывает новое семейство моделей Astra, которое позволит нескольким AI-агентам работать совместно над решением сложных задач на протяжении нескольких часов или дней. Это шаг к созданию автономных систем, способных выполнять длительные цепочки действий.

**Что произошло**
OpenAI объявила о создании нового семейства моделей Astra. Ключевая особенность — возможность координации нескольких агентов для решения задач, требующих продолжительного времени (часы или дни). Таким образом, Astra ориентирована на сценарии, где один агент не справляется, а требуется коллективный интеллект.

**Что изменилось по сравнению с предыдущей версией**
Информация о предыдущих версиях отсутствует. Astra является новым направлением, не связанным напрямую с предыдущими моделями GPT.

**Цены и доступность**
Детали о стоимости, дате выхода и регионах доступности пока не раскрыты.

**Почему это важно**
Мультиагентные системы — одно из перспективных направлений в AI. Astra демонстрирует, что OpenAI делает ставку на долгосрочные автономные сценарии, где агенты могут планировать и выполнять сложные цепочки действий без постоянного вмешательства человека. Это может привести к новым возможностям в автоматизации исследований, разработки и бизнес-процессов.

**Для пользователей AI-Sphere**
Для пользователей, следящих за развитием AI, Astra открывает горизонт для более сложных и длительных задач. Возможно, в будущем такие модели появятся в API OpenAI, что позволит создавать приложения с многодневными рабочими процессами. Рекомендуем следить за обновлениями в карточке модели на ai-sphere.ru.
