**Кратко:** Сотрудники сервиса для создания презентаций NextSlide теперь работают над ChatGPT. Переход команды может сигнализировать о намерении OpenAI добавить в ChatGPT возможности по созданию слайдов.

**Что произошло**

Члены команды NextSlide, стартапа, специализирующегося на инструментах для создания презентаций, перешли к работе над ChatGPT. Другие детали (сумма сделки, дата объявления, количество сотрудников и планы по интеграции функций) не раскрыты.

**Что изменилось по сравнению с предыдущей версией**

Ранее NextSlide существовал как независимый продукт. Теперь его разработчики задействованы в развитии ChatGPT, что расширяет экспертизу команды OpenAI в области презентационных инструментов.

**Цены и доступность**

Информация о стоимости или сроках внедрения новых функций в ChatGPT не предоставлена.

**Почему это важно**

Привлечение команды узкопрофильного сервиса может означать, что OpenAI планирует добавить в ChatGPT возможности по созданию презентаций. Это усилило бы конкуренцию с существующими AI-инструментами для работы с контентом.
