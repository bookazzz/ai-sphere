# Anthropic выпустит API для обнаружения водяных знаков в текстах Claude

**Кратко:** Anthropic сообщила, что вскоре предоставит API для обнаружения водяных знаков. Любой разработчик сможет проверить, написан ли текст моделью Claude. Решение повышает прозрачность использования AI-генерации.

**Что произошло**

Anthropic объявила о планах запустить API, позволяющий третьим сторонам проверять, был ли текст создан моделью Claude. Сервис будет работать на основе встроенных водяных знаков — меток, незаметных для человека, но выявляемых автоматически. Компания не назвала точную дату, но пообещала выпустить API вскоре.

**Что изменилось по сравнению с предыдущей версией**

Ранее у Claude не было публичного инструмента для проверки происхождения текста. Теперь Anthropic вводит механизм верификации, аналогичный тем, что уже используют некоторые конкуренты. Это первый шаг к формальной атрибуции AI-контента со стороны компании.

**Цены и доступность**

API будет доступен через облачную платформу Anthropic. Стоимость и региональные ограничения пока не объявлены. Компания лишь подтвердила, что запуск состоится в ближайшее время.

**Почему это важно**

Водяные знаки становятся стандартом для ответственного AI. Они позволяют educational-платформам, новостным редакциям и соцсетям выявлять автоматически сгенерированные тексты. Это снижает риски дезинформации и плагиата. Anthropic следует за трендом, укрепляя доверие к своей экосистеме.
