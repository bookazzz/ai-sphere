# Claude Code включает Auto Mode по умолчанию для Pro, Max и Team

**Кратко:** С 14 августа Claude Code будет поставляться с Auto Mode, включённым по умолчанию для тарифов Pro, Max и Team. Это изменение упрощает взаимодействие с инструментом, автоматически выбирая оптимальный режим выполнения команд.

**Что произошло**

Anthropic объявила, что начиная с 14 августа Claude Code будет поставляться с Auto Mode, включённым по умолчанию для тарифов Pro, Max и Team. Ранее пользователям приходилось вручную включать этот режим.

**Цены и доступность**

Функция доступна для всех пользователей тарифов Pro, Max и Team с 14 августа. Дополнительная плата за Auto Mode не взимается.

**Почему это важно**

Auto Mode автоматически определяет, как лучше выполнять команды — в диалоговом или автоматическом режиме. Это снижает порог входа для новых пользователей и ускоряет работу опытных разработчиков, избавляя их от ручного переключения.

**Для пользователей AI-Sphere**

Если вы используете Claude Code, проверьте настройки после 14 августа: Auto Mode будет включён по умолчанию. Это особенно полезно при автоматизации рутинных задач и интеграции в CI/CD-пайплайны.
