# OpenAI тестирует прозрачный фон для GPT-Image-2 через API

**Кратко:** OpenAI предварительно анонсировала поддержку прозрачного фона для модели GPT-Image-2. Функция доступна через API и позволяет генерировать PNG-изображения без фона.

**Что произошло**

OpenAI предоставила предварительную версию поддержки прозрачного фона для модели GPT-Image-2. Возможность активируется через API и позволяет генерировать изображения в формате PNG без фона.

**Что изменилось по сравнению с предыдущей версией**

Предыдущая версия GPT-Image не поддерживала прозрачный фон. Новая функция GPT-Image-2 добавляет возможность генерации PNG с альфа-каналом, что расширяет сценарии использования модели для дизайна и верстки.

**Цены и доступность**

Функция доступна в предварительной версии через API OpenAI. Информация о стоимости и регионах пока не раскрыта.

**Почему это важно**

Прозрачный фон — ключевая возможность для графического дизайна, создания логотипов, иконок и веб-элементов. Интеграция этой функции непосредственно в генерацию, а не через постобработку, упрощает рабочий процесс и повышает качество результата.

**Для пользователей AI-Sphere**

Разработчики и дизайнеры, использующие API OpenAI, теперь могут генерировать изображения с прозрачным фоном без дополнительных инструментов. Это упрощает создание контента для веба и приложений. Следите за обновлениями в карточке модели GPT-Image-2 на ai-sphere.ru.
