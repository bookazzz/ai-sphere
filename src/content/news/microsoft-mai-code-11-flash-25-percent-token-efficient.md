# Microsoft представила MAI Code 1.1 Flash: на 25% эффективнее по токенам

**Кратко:** Microsoft выпустила новую версию модели для кода — MAI Code 1.1 Flash. По заявлению компании, модель на 25% эффективнее по токенам по сравнению с предшественником MAI-Code-1-Flash.

## Что произошло

Microsoft анонсировала MAI Code 1.1 Flash — обновлённую версию своей модели для генерации и анализа кода. Ключевое улучшение — повышение эффективности использования токенов на 25% относительно предыдущей версии MAI-Code-1-Flash. Это означает, что модель способна выполнять те же задачи с меньшим количеством токенов, что потенциально снижает затраты на вычисления и ускоряет обработку запросов.

## Что изменилось по сравнению с предыдущей версией

По сравнению с MAI-Code-1-Flash новая модель MAI Code 1.1 Flash демонстрирует на 25% большую токенную эффективность. Другие характеристики, такие как архитектура, размер контекста или поддерживаемые языки программирования, не уточняются.

## Цены и доступность

Информация о стоимости и дате выхода MAI Code 1.1 Flash не раскрывается. Модель доступна через платформу Microsoft Azure.

## Почему это важно

Повышение эффективности по токенам — ключевой тренд в области языковых моделей. Для разработчиков, использующих AI-ассистентов, это означает снижение операционных расходов и потенциально более быстрый отклик. Microsoft продолжает усиливать свои позиции в сегменте AI для кода, конкурируя с решениями от OpenAI, Google и других вендоров.
