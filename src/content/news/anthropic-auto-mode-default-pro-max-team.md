**Кратко:** С 14 августа для аккаунтов Claude Pro, Max и Team авторежим становится выбором по умолчанию. Это избавляет пользователей от ручного переключения между моделями.

**Что произошло**
Anthropic объявила, что авторежим будет включён по умолчанию для всех пользователей планов Pro, Max и Team. Изменение вступает в силу 14 августа.

**Что изменилось по сравнению с предыдущей версией**
Ранее для использования авторежима требовалось активировать его вручную. Теперь он будет предустановлен, что сокращает количество действий при каждом запросе. Другие изменения не объявлены.

**Цены и доступность**
Функция становится доступна автоматически для существующих подписчиков Pro, Max и Team без дополнительной платы. Дата внедрения — 14 августа.

**Почему это важно**
Автоматический выбор модели снижает когнитивную нагрузку на пользователя и ускоряет работу. Это может повысить эффективность использования Claude для задач, где оптимальная модель не очевидна.

**Для пользователей AI-Sphere**
Владельцам аккаунтов Claude с подпиской Pro, Max или Team стоит проверить настройки после 14 августа — возможно, автоматический выбор изменит поведение привычных сценариев. Если вы используете Claude через API, убедитесь, что ваши интеграции учитывают новое поведение по умолчанию.
